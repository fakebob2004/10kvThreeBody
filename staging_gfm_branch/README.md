# GFL Switching Inverter Reference Model

This repository is a readable, staged MATLAB/Simulink reference implementation
for a grid-following renewable-energy inverter. The current delivered stages are
**B0: passive electrical skeleton** and **B1: modulation and switching**.

## Delivered in B0

- `GFL_Inverter_B0.slx` (generated model asset)
- controllable/ideal DC source connected directly to the converter DC rails
- DC-link capacitor and `Vdc` measurement
- detailed three-phase two-level switching converter with an explicit six-gate interface
- three-phase series `Rf + Lf` filter
- two-winding step-up transformer
- PCC voltage/current measurement
- explicit three-phase `Rg + Lg` grid equivalent
- grounded three-phase grid source
- four-block top-level hierarchy with all diagnostic monitors kept internal
- centralized parameter scripts and automated structural checks

The B0 controller intentionally commands all six switches off. PWM and active
switching are B1 work; this keeps B0 focused on electrical connectivity and
parameter transparency.

## Delivered in B1

- `GFL_Inverter_B1.slx`, while preserving the frozen B0 model
- normalized three-phase sinusoidal references with visible 0/-120/+120 degree phases
- explicit `[-1, 1]` triangular carrier
- graphical carrier comparison and complementary gate generation
- documented gate order: `GaH, GaL, GbH, GbL, GcH, GcL`
- converter-terminal `Vabc_inv`, `Vll_inv`, and `Iabc_sw` measurements
- signal logging plus structural and detailed-switching smoke tests

B1 remains open-loop by design. PLL and dq measurement are B2 work.

## Independent GFM-BESS branch

The 5 MW / 10 MWh GFM work is deliberately separated from B0/B1:

- `GFM_BESS_Plant_C0.slx` is generated by a copied, branch-local plant builder;
- `GFM_Inverter_C0.slx` adds the readable graphical GFM controller;
- the GFM build chain does not use `GFL_Inverter_B0.slx` or
  `GFL_Inverter_B1.slx` as a source model;
- its detailed bridge uses 1 V gate commands, a 0.5 V threshold, and
  no-dynamics antiparallel diodes.

Rebuild and validate this branch with:

```matlab
run(fullfile('Scripts','build_gfm_plant_c0_model.m'))
run(fullfile('Scripts','build_gfm_c0_model.m'))
run_gfm_c0_checks
run_gfm_c0_active_switch_test
run_gfm_c0_operating_point
```

The active-switch test is passed. The 5 MW closed-loop operating point remains
a control-commissioning item; see `docs/GFM_C0_ARCHITECTURE.md` for measured
status rather than treating switch conduction as proof of rated power.

## Quick start

In MATLAB R2026a with Simulink, Simscape, and Simscape Electrical:

```matlab
cd(fileparts(which('README.md')))  % or cd to this repository
init_project
open_system('GFL_Inverter_B0')
run_b0_checks
run_b0_smoke_test
open_system('GFL_Inverter_B1')
run_b1_checks
run_b1_smoke_test
run_b1_operating_point_test
```

To recreate the model asset after editing the build script:

```matlab
run(fullfile('Scripts','build_b0_model.m'))
run(fullfile('Scripts','build_b1_model.m'))
```

See `docs/ARCHITECTURE.md`, `docs/GFM_C0_ARCHITECTURE.md`, `docs/TEST_PLAN.md`, and
`docs/PROVENANCE.md` for design decisions and the staged validation plan.
