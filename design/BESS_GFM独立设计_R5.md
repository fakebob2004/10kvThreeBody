# BESS-GFM 独立设计与双向功率验证（R5）

## 1. 本阶段边界

本阶段只设计并验证 BESS 的 GFM 支路，没有改动 PV、风电或 R2 联合系统。PV 和风电后续仍按 GFL 处理。

采用两级验证：

- R4：受控三相电压源等值，先验证 10 kV 电压骨架、变压器、LCL、P-f/Q-V 下垂和 SOC 符号。
- R5：用电池 Thevenin 等值、DC-link 和双向平均值三相 VSC 替换理想交流源，验证真实双向功率方向。

## 2. 容量选择

本阶段容量为：

| 项目 | 数值 |
|---|---:|
| BESS 有功额定 | 2.5 MW |
| BESS 能量 | 2.0 MWh |
| 持续时间 | 0.8 h（额定功率） |
| PCS/变压器容量 | 3.15 MVA |
| 电池名义电压 | 1200 V |
| 等效容量 | 1666.7 Ah |
| SOC 正常窗口 | 20%-90% |
| 初始 SOC | 60% |

2.5 MW 是 10 MW 风光装机的 25%，用于成网、快速功率平衡和短时削峰，不按“完全吞下全部风光出力”配置，因此比原先直接按 5 MW/4 MWh 放大更经济。2 MWh 可在额定功率下持续 0.8 h，属于功率支撑型而非长时能量搬移型配置。最终经济容量仍需用实测/预测负荷与风光时序做年度优化；当前值是动态模型的合理工程起点。

## 3. 电压链路与是否需要二次变换

R5 电压链路为：

`1200 V 电池等值 → DC-link → 双向平均值 VSC → 690 V LCL → 0.69/10 kV 变压器 → 10 kV 母线`

690 V 线电压所需理论最小直流电压（调制深度 1）为：

`Vdc,min = 2*sqrt(2/3)*690 = 1126.8 V`

本次放电工况的 DC-link 为 1192.34 V、调制深度为 0.9399，因此 1200 V 名义电池可直接支撑 690 V PCS，不需要为了名义电压再增加一级 DC/DC，也不需要再变一次交流电压。

但这个结论有边界：若真实电池在低 SOC、低温和大电流下端电压会低于约 1150 V（计入 0.98 调制上限），则应加入双向升降压 DC/DC，或重新选择电池串联节数/PCS 交流额定电压。R5 的电池等值目前保持 1200 V OCV，尚未覆盖完整 SOC-温度电压曲线。

## 4. 主要电气与控制参数

| 项目 | 数值 |
|---|---:|
| 变压器 | 3.15 MVA，0.69/10 kV，低压 Δ / 高压 Yg |
| 变压器总电阻 | 0.01 pu |
| 变压器总漏抗 | 0.06 pu |
| L1 / L2 | 38.49 / 14.43 uH/相 |
| R1 / R2 | 0.756 / 0.756 mΩ/相 |
| C | 1.053 mF/相 |
| 阻尼电阻 | 约 0.033 Ω |
| DC-link 电容 | 0.05 F（聚合平均值模型） |
| 电池内阻 | 0.006 Ω |
| P-f 下垂 | 0.2 Hz/MW（2.5 MW 时下降 0.5 Hz） |
| Q-V 下垂 | 13.8 V/Mvar（2.5 Mvar 时下降 5%） |
| 调制上限 | 0.98 |

控制器不依赖 PLL 建立相角。测量有功经低通后形成频率偏差，绝对角速度积分得到 VSC 电角度；测量无功通过 Q-V 下垂形成 690 V 侧线电压幅值。调制深度使用实测 DC-link 前馈计算，并经过 0.98 限幅。Vdc 前馈加入 0.5 ms 测量滤波，以消除代数环。

## 5. 自动验证结果

测试负荷根据 BESS 能力调整，放电工况为 `1.5 MW + j0.30 Mvar`；吸收功率工况使用 `-0.5 MW` 的负恒功率负荷模拟外部过剩电源。

| 工况 | P | Q | Vdc | Idc | Pdc | f | 调制深度 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 放电 | 1.5058 MW | 0.2716 Mvar | 1192.34 V | +1277.41 A | +1.5231 MW | 49.69885 Hz | 0.9399 |
| 充电/吸收 | -0.4999 MW | -0.0031 Mvar | 1202.48 V | -412.93 A | -0.4965 MW | 50.09998 Hz | 0.9371 |

正电流/正直流功率表示电池放电，负电流/负直流功率表示电池吸收功率。两种工况均满足：

- `|P| < 2.5 MW`；
- `sqrt(P^2+Q^2) < 3.15 MVA`；
- DC 电流低于 1.2 pu；
- DC-link 高于可行调制电压；
- 调制器未饱和；
- P-f 与 Q-V 下垂方程数值一致；
- 放电时 SOC 下降，吸收功率时 SOC 上升。

因此，用户关心的“GFM BESS 是否必须有时吸收 P、能否做到”在 R5 中已用物理双向 DC/AC 功率流验证：可以，且不需要切换成 GFL。

## 6. 当前模型边界

R5 是平均值 PCS，可用于系统级暂态、容量与控制协同验证，但还不是开关级硬件模型。当前尚未加入：

- SOC/温度相关电池 OCV 与电阻；
- dq 电流内环和虚拟阻抗限流；
- SOC 触边、功率斜率、抗积分饱和与保护状态机；
- 预充、接触器和故障穿越；
- PWM、器件损耗和 THD。

下一步在仍不修改 PV/风电的前提下，应先给 R5 加 1.2 pu 电流限制和负荷阶跃测试，再把通过验证的 BESS-GFM 子系统接入联合模型。
