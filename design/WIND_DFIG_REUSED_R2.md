# 双馈风机平均值模型 R2：复用基座与接口说明

## 1. 定位

`Wind_DFIG_Reused_R2.slx` 是当前推荐的双馈风机模型。R1 仅保留为 DFIG/RSC 控制算法原型；R2 直接从已经验收的 `Wind_DirectDrive_Average.slx` 复制并局部替换，因此不是重新画一套外观相似的系统。

## 2. 实际复用范围

| 顶层模块 | R2 处理 | 说明 |
|---|---|---|
| 01 Wind Turbine Aerodynamics | 原样复用 | 风速、气动转矩和惯量链不重建 |
| 02 Generator/MSC | 替换 | 改为绕线式 DFIG dq 平均模型与转子侧平均变流器 RSC |
| 03 DC Link and Average GSC | 原样复用 | 保留 1500 V 直流母线、预充电和平均 GSC 物理网络 |
| 04 GFL Control | 原样复用 | 保留 PLL、电流环、直流电压环和调制接口 |
| 05 Filter Transformer and PCC | 主链复用，局部扩展 | 原 Rf+Lf、0.69/10 kV 变压器和 PCC 测量不变，只在 690 V 母线增加 DFIG 定子平均电流支路 |
| 06 Grid Equivalent and Source | 原样复用 | 电网等值和理想三相电源不重建 |

R2 只新增两个本质模块：`02 Wound-Rotor DFIG dq Plant` 与 `03 Rotor-Side Average Converter Control`。原 R1 中已经验证的 DFIG/RSC 算法块被复制到 R2，而其下游功率链没有重复构造。

## 3. 功率与符号约定

- 定子功率通过 690 V 母线上的三相平均电流源送入原变压器/PCC 物理网络。
- 转子滑差功率使用 `P_rotor_to_dc_W` 接入原模型的直流功率端口。
- 亚同步工况下转子从直流侧吸收功率，因此 `P_rotor_to_dc_W < 0`；这不是符号错误。
- 生成电磁转矩沿原气动轴的约定为负值。
- dq 到 abc 的相序采用 A: 0、B: +120°、C: -120°，已通过正序/负序比校验。

## 4. 连线布局原则

顶层保留原物理功率链的水平主轴；转速/转矩信号位于上方信号带，转子功率和控制信号位于下方信号带。`Te` 端口放在 DFIG 子系统左侧，避免跨越整个子系统回接气动模块。

在 05 内部，DFIG 定子电流源位于变压器低压母线正下方，以一根局部竖线接入；物理量转换器与其输入端口相邻。PCC 电压、电流测量沿原路径留在右侧，不把诊断端口暴露到顶层。

运行：

```matlab

```

验证器同时检查复用层级存在、DFIG/RSC 新模块存在、RSC 内无载波/PWM 开关链、物理功率有效传输，以及 dq 与 abc 功率的一致性。

## 6. 当前边界

这是面向课程作业和后续控制研究的平均值模型：DFIG 电磁部分和 RSC 使用显式 dq 信号域模型，定子通过受控三相平均电流源接入 Simscape 物理网络；没有构造详细开关型 RSC。当前沿用基座模型的直流电容和滤波电感初值松弛警告，但仿真可收敛并通过稳态断言。

后续若研究 LVRT、crowbar 或转子过流保护，应在 R2 的 02 子系统内扩展，而不应重建 03--06 的共享功率链。
